# Sistemas Autônomos e Protocolos IGP e EGP

Os protocolos de roteamento interior (IGPs) foram criados para utilização em uma rede cujas partes estejam sob controle de uma única organização. Os critérios de projeto para um protocolo de roteamento interior exigem que ele encontre o melhor caminho através da rede interior, ou seja, a métrica e a maneira como essa métrica é utilizada são os elementos mais importantes em um protocolo de roteamento interior. 

Já um protocolo de roteamento exterior (EGPs) são concebidos para a utilização entre duas ou mais redes diferentes, que estejam sob o controle de diferentes organizações. Geralmente, esses protocolos de roteamento são utilizados entre provedores de serviço de Internet ou entre a interligação de grandes redes de uma mesma empresa. 
Os protocolos de gateway IP exteriores requerem três conjuntos básicos de informações antes de iniciar o roteamento, são eles: 

* Lista de roteadores vizinhos com os quais possam trocar informações de roteamento entre si;
* Lista de redes para poder anunciar como diretamente alcançáveis;
* O número que identifica um sistema autônomo do roteador local.

Um protocolo de roteamento exterior deve então isolar os sistemas autônomos, que são gerenciados por diferentes administrações.
Estes sistemas autônomos (AS) possuem um número de identificação, que são atribuídos pelo ARIN (American Registry of Internet Numbers) ou por um provedor de serviços de Internet. Esse número de identificação possui 16 bits de tamanho. Como por exemplo, os protocolos RIPv1, RIPv2, IGRP, EIGRP, OSPF e IS-IS são considerados protocolos IGP, já o EGP e o BGP são considerados protocolos EGP.

## Classes de Protocolos

Os protocolos de roteamento dinâmico fazem parte de pelo três classes, considerando-se protocolos interiores (IGPs), ou seja, protocolos que atuam dentro de um sistema autônomo (AS).

A maioria dos algoritmos de roteamento podem então ser classificado em uma destas três categorias:

### Vetor Distância ( distance vector) 

Método utilizado por alguns protocolos de roteamento para que os roteadores aprendam caminhos até outras redes. Ele funciona de forma colaborativa: cada roteador envia para os vizinhos uma tabela contendo a distância até cada destino conhecido. Com isso, cada roteador vai atualizando sua própria tabela com base nas informações recebidas.

Características principais:
 * Cada roteador conhece apenas os destinos e a distância, não a topologia completa da rede.
 * A distância pode ser métrica de hops (saltos), custos, ou outra medida definida pelo protocolo.
 * O roteador escolhe sempre o melhor caminho com menor distância.
 * As informações são trocadas periodicamente com vizinhos.

Protocolos que usam Distance Vector
 * RIP (Routing Information Protocol)
 * EIGRP ( Enhanced Interior Gateway Routing Protocol)

Vantagens
 * Simples de configurar e entender
 * Baixo uso de recursos

Desvantagens
 * Convergência lenta
 * Pode sofrer com contagem até o infinito
 * Menos escalável que protocolos baseados em Link-State

Funcionamento Resumido
1. O roteador envia para cada vizinho sua tabela de rotas.
2. O vizinho recebe, soma sua métrica ao caminho informado e atualiza sua tabela. 
3. A informação se propaga pela rede.
4. A melhor rota sempre será a de menor distância.

###  Estado do Enlace ou Link (link state) - 

É um método de roteamento em que cada roteador constrói uma visão completa da topologia da rede. Em vez de apenas trocar distâncias com vizinhos, os roteadores enviam informações detalhadas sobre o estado dos seus enlaces, quem são seus vizinhos e a condição desses links.

#### Com funciona?
1. Cada roteador  descobre seus vizinhos diretamente conectados.
2. Ele criar uma mensagem chamada LSA ( Link State Advertisement) contendo:
 * Quem são seus vizinhos.
 * Custo dos enlaces.
3. Essa mensagem é inundada pela rede, chegando a todos os roteadores do mesmo domínio.
4. Assim, todos têm a mesma visão completa da topologia.
5. Cada roteador roda o próprio algoritmo SPF (Dijkstra) para calcular o melhor caminho até cada destino.

Protocolos que usam o Link State
* OSPF
* IS-IS

Vantagens 
* Convergência muito rápida.
* Alta Escalabilidade.
* Menor risco de loops.
* Conhecimento completo de topologia.

Desvantagens
* Requer mais CPU e memória.
* Processo mais complexo que o vetor de distância.

Funcionamento Resumido
* Todos conhecem toda a topologia.
* Todos calculam suas próprias melhores rotas.
* Mudanças são propagadas rapidamente via LSAs.
* O cálculo é baseado em custo e não apenas em saltos.

###  Híbrido ou Vetor de Distância Avançado ( Cisco Vendor).

É uma abordagem utilizada pelos protocolos como o EIGRP. Ele combina característicasa dos algoritmos de Vetor de Distância e Link State, tornando-se um modelo híbrido, mais eficiente e rápido do que os protocolos tradicionais. 

### Porque que é considerado híbrido?

Ele mistura os aspectos dos dois mundos:

* Vetor de Distância
  * Troca de informações com vizinhos.
  * Atualização incrementais.
  * Facilidade de implementação.

* Link State
 * Convergência rápida.
 * Conhecimento mais detalhado da rede.
 * Uso de métricas múltiplas e precisas.

### Principais características do EIGRP

* Utiliza o algoritmo DUAL ( Diffusing Update Algorithm), que garante convergência rápida e livre de loops.
* Suporta múltiplas métricas: largura de banda, atraso, confiabilidade, carga e MTU.
* Envia apenas atualizações parciais e quando necessário, reduzindo consumo de banda.
* Mantém tabelas específicas:
  * Neighbor Table
  * Topology Table
  * Routing Table
Possui mecanismos para escolher rotas primárias(sucessor) e de backup (sucessor feasible).

### Vantagens
* Convergência muito rápida
* Eficiência no uso de banda
* Alto desempenho em redes médias e grandes.
* Possui rota alternativas pré-calculadas.
* Reduz risco de loops com o DUAL.

### Desvantagens
* Proprietário Cisco.
* Complexidade maior em comparação ao RIP.
* Requer mais CPU e memória.

### Procolos que usam essa abordagem 
* EIGRP



## Roteamento de Vetor Distância
A Abordagem de roteamento pelo vetor da distância determina uma direção (vetor) e uma distância para qualquer link direto de um grupo de redes interconectadas. Já abordagem dado ao estado dos links, também chamada de "shortest path first", recria uma topologia exata de todo o grupo o grupo de redes interconectadas dentro um sistema autônomo.
